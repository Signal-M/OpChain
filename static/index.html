📌 标注模式 · 拖框定义点击区域

      
    

    

      ⚠️ 当前 OCR 引擎 = mock（假定位）：text / template 模式会在区域内做二次定位，但 mock 永远把点击甩到屏幕左上角固定点，会导致「点得离标注非常远」。

      请统一用 center（点区域中心） 模式——它不依赖 OCR，在这台 Mac 上实测零误差。

      若确实需要按文字/图标点击，请在启动器里设置 OCR=real 并安装真实 OCR（paddleocr + opencv）。
    

    

      

        
        
        

          
          
        

        
在截图上按住拖拽画出区域 = 一个步骤；可画多个。点击框可选中，拖动框体移动、拖右下角手柄调整大小。
区域会自动存为归一化坐标（抗窗口移动 / Retina），适合标准化的固定位置按钮。
多页流程：第①步画在页面1，要加第②步在页面2时，先点画布新建一个占位框（第②步），选中它，手动把微信切到页面2，再点「重新截屏」（只更新选中那一步的截图，不会清空其它步骤），然后拖动该框到按钮位置。
截图中必须是【微信小程序】界面（不是本网页）。若截到的是网页，请先把微信作为普通窗口放在本网页之后，再点「重新截屏」。
